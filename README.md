# 中学校英語単語帳 V2.4
## 例文全面校正版

収録単語数：571語

### V2.4 の重点
- 旧版の機械的で不自然な例文を全面的に差し替え
- 中学生が理解しやすい短い英文を優先
- 英文・日本語訳・中国語訳の意味対応を改善
- 英語例文は米式英語（en-US）で読み上げ
- 日本語訳（ja-JP）、中国語訳（zh-CN）も読み上げ可能
- UK / US IPA、英式 / 米式単語発音を維持
- 4択練習、未習得復習、学習進捗、端末保存、ダークモードを維持
- 高校入試重要語彙、不規則動詞重点表を維持

※ 自動生成で不自然な動詞活用を作らないため、個別校正できていない語では
「We learned the word “...” today.」という安全な学習文を使用しています。
今後、重要語から順に個別の自然な用例へ置き換えられます。
